# tv_server

Домашний «сервер для телевизора» на Windows-ПК. Он нужен, чтобы смотреть торренты через **Lampa** в **Media Station X (MSX)** на телевизоре (проверено на LG webOS 10).

- **Lampa** раздаётся с ПК по локальной сети небольшим веб-сервером **Caddy** (служба Windows).
- **TorrServer** на том же ПК качает торрент и отдаёт видео потоком.
- **Панель управления** (ярлык на рабочем столе) показывает статус. Кнопки в ней запускают и останавливают Lampa и TorrServer и открывают их веб-интерфейсы.

---

## Зачем это нужно

По умолчанию MSX открывает Lampa с публичного адреса `http://lampa.mx`. Браузерный движок телевизора (Chromium 120+) запрещает публичным страницам обращаться к адресам локальной сети. Это механизм *Private Network Access*, в консоли он пишет ошибку:

> request client is not a secure context and the resource is in more-private address space

Поэтому Lampa из MSX **не видит TorrServer** на `192.168.x.x`.

Если открыть Lampa с локального адреса (`http://192.168.x.x:8095/`), блокировки нет: и страница, и TorrServer находятся в одной сети. Этот проект делает именно это.

```
 Телевизор (MSX)                         Windows-ПК (192.168.x.x)
 ┌──────────────┐  http://IP:8095/msx/  ┌───────────────────────────────┐
 │ Media Station│ ─────────────────────▶│ Caddy (служба LampaWeb)       │
 │ X  → Lampa   │  start.json, Lampa    │   %USERPROFILE%\LampaWeb\site │
 │              │                       │                               │
 │              │  http://IP:8090/      │ TorrServer (задание + сторож) │
 │              │ ─────────────────────▶│   %USERPROFILE%\TorrServer    │
 └──────────────┘                       └───────────────────────────────┘
```

## Быстрая установка (для друзей)

1. **Закрепите IP за ПК в роутере** (DHCP reservation / «Привязка IP к MAC»), иначе после перезагрузки адрес может смениться.
2. **TorrServer** (если ещё не стоит):
   - скачайте `TorrServer-windows-amd64.exe` со страницы https://github.com/YouROK/TorrServer/releases;
   - положите его в `%USERPROFILE%\TorrServer\` и переименуйте в `TorrServer.exe`;
   - запустите:
     ```powershell
     powershell -ExecutionPolicy Bypass -File .\torrserver\install-torrserver.ps1
     ```
3. **Lampa + веб-сервер + панель**:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```
   Скрипт сам попросит права администратора (окно UAC) и в конце напечатает адрес для телевизора.
4. **Телевизор**: см. раздел [Настройка телевизора](#настройка-телевизора).

Команды запускаются из папки репозитория: Shift + правый клик по папке → «Открыть окно PowerShell здесь».

## Что делает `install.ps1`

| Шаг | Что происходит |
|---|---|
| Сеть | Находит IPv4 ПК в локальной сети: интерфейс со шлюзом, частный диапазон, VPN-адреса с маской /32 отсекаются. Если адресов несколько, просит указать `-Ip`. |
| Порт | Проверяет, что порт (по умолчанию **8095**) свободен. Если занят, останавливается и предлагает `-Port`. |
| Lampa | Скачивает официальный webOS-пакет `lampa_v3.1.7.ipk` с GitHub yumata/lampa и **сверяет SHA-256**. Если сумма не совпала, установка останавливается. |
| Распаковка | `.ipk` — это ar-архив, его читает встроенный `tar.exe`. Затем распаковывается `data.tar.gz`, и из него берётся `usr\palm\applications\lampa.tv` → `%USERPROFILE%\LampaWeb\site\`. |
| Торренты | В `index.html` заменяется ровно одна строка `torrents_use: false,` на `true,`: webOS-сборка выключает торренты. Замена делается побайтово, остальное содержимое файла не меняется. |
| MSX | Создаётся `site\msx\start.json` (UTF-8 без BOM) с адресом этого ПК. |
| Настройки Lampa | Создаётся `site\tvserver.js` и подключается в `index.html` перед `loader.js`. При первом запуске Lampa на устройстве он сам прописывает адрес TorrServer этого ПК, включает парсер (Jackett `https://jr.maxvol.pro`, ожидание 30 с) и ставит метку `tvserver_defaults`. После этого ваши изменения в настройках Lampa он не трогает. |
| Caddy | Скачивает последний релиз `caddy_*_windows_amd64.zip` с GitHub caddyserver/caddy и **сверяет с `checksums.txt`** того же релиза. Ставит в `%USERPROFILE%\Caddy\caddy.exe` и пишет `Caddyfile`: http на порту, без листинга каталогов, без админ-порта. |
| Панель | Копирует `panel\*` в `%USERPROFILE%\LampaWeb\panel\`, пишет `config.json`, делает иконку и ярлык «Lampa сервер» на рабочем столе. |
| Служба | Служба Windows **LampaWeb**: автозапуск при старте Windows (до входа в систему), от LocalSystem, **перезапуск при сбое через 60 с**. |
| Брандмауэр | Входящие подключения на TCP-порт для `caddy.exe` **только из своей локальной подсети** (например, `192.168.31.0/24`). Профиль сети не меняется. |
| Проверка | Запрашивает по IP (не localhost) `/`, `/loader.js`, `/msx/start.json` и `:8090/echo` (TorrServer). |

Повторный запуск безопасен. Так обновляется Lampa или Caddy, так же меняется порт или IP: служба перенастраивается, правило брандмауэра пересоздаётся.

### Параметры

```powershell
.\install.ps1 -Ip 192.168.1.50      # указать адрес вручную
.\install.ps1 -Port 8096            # другой порт (потом поменять адрес в MSX)
.\install.ps1 -TorrPort 8090        # порт TorrServer (для проверки и панели)
.\install.ps1 -JackettUrl https://parser.example   # другой Jackett-парсер ('' — не прописывать парсер)
.\install.ps1 -FilesOnly            # только файлы, без службы/брандмауэра/ярлыка (без прав админа)
.\install.ps1 -LampaIpk .\lampa.ipk -CaddyZip .\caddy.zip -CaddyChecksums .\checksums.txt   # без скачивания
```

Другая версия Lampa: `-LampaUrl <ссылка на .ipk> -LampaSha256 <sha256>`. Хеш смотрите в поле `digest` через API: `https://api.github.com/repos/yumata/lampa/releases`.

### Почему служба, а не Планировщик заданий

Перезапуск при сбое в Планировщике срабатывает, только когда задание не смогло **запуститься**. Если уже работающий процесс упал или его убили, задание считается выполненным, и никто его не поднимает. Это проверено. У службы Windows восстановление после сбоя срабатывает и в этом случае. Caddy официально умеет работать как служба (`caddy run`).

## Настройка телевизора

1. Установите **Media Station X** из магазина приложений телевизора (LG Content Store).
2. Откройте MSX → **Settings** → **Start Parameter** → введите:
   ```
   http://192.168.x.x:8095/msx/start.json
   ```
   Точный адрес печатает `install.ps1`, его же копирует кнопка «Адрес для MSX» в панели.
3. Перезапустите MSX: откроется Lampa с вашего ПК.
4. Адрес TorrServer и парсер Lampa пропишет сама при первом запуске (`tvserver.js`). В карточке фильма должна появиться кнопка **«Торренты»**. Проверить или поменять можно в **Настройки → TorrServer** и **Настройки → Парсер**.

Кнопка «Торренты» появляется, только если включён парсер: он ищет раздачи по названию фильма, а TorrServer потом их проигрывает. `jr.maxvol.pro` — бесплатный публичный Jackett. Он отвечает 5–15 секунд, поэтому ожидание выставлено в 30 с. Он собирает раздачи сразу с нескольких трекеров: kinozal, rutracker, rutor, nnmclub, bitru, megapeer, korsars, torrentby. Если он перестанет работать, укажите другой адрес Jackett в панели («Сменить парсер…») или в Lampa (Настройки → Парсер). Публичные парсеры часто закрываются: например, `jac.red` в ноябре 2026 отвечал 403.

ПК должен быть включён, а телевизор подключён к той же домашней сети.

## Панель управления

Ярлык **«Lampa сервер»** на рабочем столе открывает окно со статусом, который обновляется каждые 10 секунд.

- **Lampa**: работает или нет, состояние службы. Кнопки «Запустить», «Остановить», «Перезапустить», «Открыть Lampa», «Папка сайта», «Адрес для MSX».
- **TorrServer**: работает или нет и версия. Кнопки «Запустить», «Остановить», «Перезапустить», «Открыть TorrServer», «Папка TorrServer».
- **Парсер торрентов**: отвечает ли Jackett (по умолчанию `https://jr.maxvol.pro`), сколько раздач нашёл и за сколько секунд. Проверка идёт в фоне раз в 2 минуты.
  - «Проверить» — проверить сейчас.
  - «Сменить парсер…» — ввести другой адрес. Он сохранится в `config.json` и пропишется на ТВ.
  - «Обновить на ТВ» — при следующем запуске MSX Lampa заново пропишет адрес TorrServer и парсер. Пригодится, если настройки на телевизоре сбились или подключаете новый телевизор, где Lampa уже открывали.

Кнопки управления спрашивают права администратора (UAC), потому что служба и TorrServer работают от SYSTEM. Если действие не удалось, панель показывает текст ошибки.

«Остановить» у TorrServer останавливает и задание, и сторож `run.ps1`, и `TorrServer.exe`. Иначе сторож поднял бы его через минуту. После остановки TorrServer запускается кнопкой «Запустить» или при перезагрузке ПК.

Файлы панели: `panel\LampaPanel.ps1` (окно, WinForms) и `panel\ServiceAction.ps1` (действия с правами админа). Настройки (IP, порты, пути, имя службы) лежат в `config.json` рядом с ними, его создаёт `install.ps1`.

## Что где лежит после установки

| Путь | Что это |
|---|---|
| `%USERPROFILE%\LampaWeb\site\` | файлы Lampa + `msx\start.json` |
| `%USERPROFILE%\LampaWeb\panel\` | панель, `config.json`, иконка |
| `%USERPROFILE%\Caddy\caddy.exe`, `Caddyfile` | веб-сервер и его настройки |
| `%USERPROFILE%\TorrServer\` | `TorrServer.exe`, сторож `run.ps1`, `watchdog.log`, база и настройки |
| Служба **LampaWeb** | `services.msc` |
| Задание **TorrServer** | Планировщик заданий (только если ставили через `install-torrserver.ps1`) |
| Правила брандмауэра | `LampaWeb Caddy TCP 8095`, `TorrServer TCP 8090` |
| Рабочий стол | ярлык «Lampa сервер» |

## Структура репозитория

```
install.ps1                     установка Lampa + Caddy + служба + брандмауэр + панель
uninstall.ps1                   удаление (служба, правило, ярлык; файлы — с -RemoveFiles)
lib\Common.ps1                  общие функции (UAC, определение IP/подсети, HTTP, загрузка)
panel\LampaPanel.ps1            окно панели управления
panel\ServiceAction.ps1         действия панели с правами администратора
panel\TvDefaults.ps1            генерация site\tvserver.js (настройки Lampa на ТВ: TorrServer + парсер)
torrserver\run.ps1              сторож TorrServer (перезапуск через 60 с после выхода)
torrserver\install-torrserver.ps1   автозапуск TorrServer: задание + брандмауэр
```

## Удаление

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1                # служба, правило, ярлык
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1 -RemoveFiles   # + папки LampaWeb и Caddy
```

TorrServer этот скрипт не трогает.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| На ТВ Lampa не открывается | Откройте `http://IP:8095/` с телефона в той же Wi-Fi-сети. Если не открывается, проверьте статус в панели, совпадает ли IP (не сменился ли) и правило брандмауэра. |
| Нет кнопки «Торренты» | Настройки → Парсер → «Использовать парсер» должно быть вкл. Если Lampa на этом устройстве уже открывали до установки `tvserver.js`, он всё равно сработает один раз при следующем запуске. |
| «Торренты» есть, но список пустой или ошибка | Парсер не ответил: увеличьте Настройки → Парсер → таймаут или смените адрес парсера. |
| Lampa открылась, но не видит TorrServer | Адрес в Lampa → Настройки → TorrServer. В MSX должен быть адрес вашего ПК, а не `lampa.mx`. Проверьте `http://IP:8090/echo` с телефона. |
| Сменился IP ПК | Закрепите IP в роутере, запустите `install.ps1` ещё раз и поменяйте адрес в MSX. |
| Порт 8095 занят | `install.ps1 -Port 8096`, затем новый адрес в MSX. |
| Сеть «Общественная» | Ничего менять не нужно: правило действует во всех профилях, но только для своей подсети. |
| Включён VPN на ПК | Не мешает, если VPN не перехватывает локальную сеть. Адреса VPN с маской /32 в «свою подсеть» не попадают. |
| `curl` пишет `CRYPT_E_NO_REVOCATION_CHECK` | Бывает с VPN. Скрипты скачивают через PowerShell, а не curl, так что их это не касается. |
| Кнопка в панели «ничего не делает» | Должно появиться окно UAC. Если его отклонить, панель так и напишет. Текст ошибки появится в окне. |
| Логи | Сторож TorrServer: `%USERPROFILE%\TorrServer\watchdog.log`. Служба: Просмотр событий → Журналы Windows → Система (источник Service Control Manager). |
